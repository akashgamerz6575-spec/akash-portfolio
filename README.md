# Akash V Portfolio

Static portfolio site for GitHub Pages.

## Deploy

1. Create a public GitHub repository named `akash-portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, choose `main`, then `/(root)`.
5. Save. The site will be served at `https://<your-github-username>.github.io/akash-portfolio/`.

No build process is required.
